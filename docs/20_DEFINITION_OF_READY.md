# Definition of Ready to Start Coding

Development can start when:

- product name/application ID are accepted as working identifiers;
- Android SDK 36 is installed;
- JDK/Android Studio compatible with chosen stable AGP;
- Git repository exists or agent is authorized to create it;
- signing is **not** required for debug development;
- no external API credential is required for MVP;
- AI agent has this pack available in repository `/docs`.

User decisions that can safely remain deferred:
- final icon
- final store screenshots
- final privacy-policy URL
- release signing key
- whether future FBR connectivity will ever be pursued
- live market-price providers

These must not block core development.
