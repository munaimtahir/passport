# Utility Tracker Product Assumptions

This document lists assumptions made during the product reset implementation.

1. **Due-soon Window:** Default is set to 5 days before the expected due date.
2. **PKR Currency:** Currencies default to PKR as this is geared towards Pakistan utility management, but standard money models from the scaffold are reused.
3. **Storage Directory:** Internal application folder is used to securely copy imported bill and payment attachments.
