# Post-MVP Roadmap

## Phase 2 — Smarter capture
- on-device document extraction
- statement import
- CSV import templates
- document-to-tax suggestions
- recurring transaction drafts

## Phase 3 — Connected but optional
Only after privacy and regulatory review:
- read-only bank aggregation through authorized mechanisms
- brokerage statement/API import
- market-price updates
- exchange-rate updates

The app must remain usable without these.

## Phase 4 — Tax ecosystem
- accountant collaboration package
- ruleset updates
- FBR-compatible structured exports where officially documented
- official submission integration only if authorized/documented interface exists

## Phase 5 — Household
- multiple local profiles
- spouse/family financial views
- encrypted handover/emergency estate package

## Phase 6 — Advanced financial intelligence
- anomaly detection
- cash-flow forecasting
- goal simulations
- tax evidence completeness suggestions

No investment advice unless deliberately designed for the associated regulatory and safety obligations.
